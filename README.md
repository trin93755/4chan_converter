Batch-convert videos into silent, size-checked WebM or MP4 files for **/pol/**.

1. **Download and extract** the whole ZIP.
2. **Open Start** (`Start.bat`, `Start.command`, or `Start.sh`).
3. **Add videos → choose WebM or MP4 → Convert.**

No developer tools or separate installations. First launch needs internet to set up the video engine; later conversions work offline. Keep the launcher window open while using the app.

![4chan gem converter](docs/preview.jpg)

**Simple** covers everyday conversion. **Advanced** adds filename prefixes/suffixes, audio-link encoding, long-video handling, and output folders.

Optional **Catbox audio** uploads a public MP3 and puts its link in the filename. Originals are kept; finished files are saved in `outputs`.
